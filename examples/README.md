# Examples

This folder contains a few simple usage examples for the project.

## Files

- `basic_terminal.py` - terminal usage with the async harvester
- `basic_gui.py` - launches the PyQt5 GUI
- `url_file_input.py` - reads URLs from a text file and harvests them

## Run examples

```bash
python examples/basic_terminal.py
python examples/basic_gui.py
python examples/url_file_input.py urls.txt
```
